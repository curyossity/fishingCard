# Coastal Print concept

6 November 2026. Art-direction proposal for review, not an approved replacement of the existing card visual contract or a gameplay specification. No Unity code, scenes, prefabs, runtime data or artwork assets were changed.

[Open the new Penpot file](https://design.penpot.app/?screen=workspace&team-id=9e056cfe-f83f-81f8-8008-cc4e858053b7&file-id=3681d377-bc58-8110-8008-e7a38adc2112&page-id=3681d377-bc58-8110-8008-e7a38adc2113).

File: **Fishing Roguelike - Coastal Print Concept**. Board: `38e9e9ec-a6d5-8050-8008-e7a44c4e0f84`. The [1920 × 1080 preview](Landing.png) is exported from editable Penpot shapes and original vector creature illustrations.

The screen shows the Landing Challenge alone. It contains no game logo/title, slot machine, surfacing control, capacity or overload system. Catch/Bait and rig insertion follow successful landing on a separate screen. The current rig supplies the illustrated bonus; the encountered Garfish is not attached.

Visual direction: a flat ink playmat, warm card stock, cut-print fish silhouettes, simple hard shadows, condensed score typography and quiet current contours. Seafoam identifies landing progress and rig support; orange identifies the primary action. Catch/Bait is distinguished by text as well as color. Existing game art is preserved.

Reference study: [Balatro official press kit](https://www.playbalatro.com/press-kit/) for score hierarchy and a calm play field; [Wildfrost official press kit](https://www.wildfrostgame.com/presskit/) for distinct illustrated card silhouettes; [Slay the Spire](https://www.megacrit.com/games/) for separation of the current encounter and supporting card information. These are visual references only; no third-party game artwork is included.

Four initial attempts, Resistance 80, 36 accumulated points, Good = 12 accuracy + 6 rig, Space input, rarity and motion are illustrative. Mackerel's Schooling bonus uses the GDD's provisional example; the depicted companion tags and all displayed creature values need content review. Technique controls are omitted while their timing remains open. The rig row establishes order without implying a three-creature limit or manual rearrangement.

Validation: exported and visually inspected; 280 Penpot descendants stay inside the gameplay board; minimum text size is 18 px at 1080p. This is a static concept, not a playable or responsive implementation. Authoring notes sit outside the gameplay frame.
