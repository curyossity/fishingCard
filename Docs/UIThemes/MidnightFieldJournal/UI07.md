# UI-07 — playable comparison scene

Open `Assets/UIThemes/MidnightFieldJournal/Scenes/MidnightFieldJournalComparison.unity` and press Play. It runs the existing game controller with the original biome, capacity, hand size, depth step and eight-design/12-card starter deck. One candidate Canvas supplies the run view, Catch Chain, perspective hand and result view. One EventSystem, the existing camera configuration and a 2D light are copied into the isolated scene. The original scene and default build list remain unchanged.

The candidate canvas now includes matching native parchment-color choice, result and settings panels. Runtime-provided labels/details remain authoritative. Choice rows are pooled, scrollable and use explicit navigation with automatic scrolling to the focused row. They deliberately omit legacy portraits; no labels are parsed to invent image mappings. Concealed encounters retain their redacted labels and blank details. Pointer presses bound to an earlier option set cannot select replacement options, and callbacks are consumed before reentrant game resolution.

The modal host blocks the main HUD, navigation and projected hand through parent input groups, preserves one visible modal and restores valid focus. Results use the controller's completed snapshots, role-aware values, Gold and existing upgrade/restart callbacks. The inactive/unconfigured Technique unlock is hidden. Settings was previously only an event; its new panel shows actual display configuration and returns to the run. It does not add adjustable preferences or gameplay rules.

Integration fixed a timing gap: Surface and Techniques now reject requests during encounter motion, along with Descend. The view's completion event refreshes controller-owned availability and hand state after the incoming card settles. Surface ascent still completes before results appear. Pending event consequences/creature choices remain controller-owned and do not reopen the Technique window.
