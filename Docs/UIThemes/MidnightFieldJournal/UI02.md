## Font provenance

Cinzel came from the official [Google Fonts Cinzel directory](https://github.com/google/fonts/tree/3dd78844021e948ceb633d1dcee3f7885561b5d9/ofl/cinzel), pinned to commit `3dd78844021e948ceb633d1dcee3f7885561b5d9`. It uses the [SIL Open Font License](https://raw.githubusercontent.com/google/fonts/3dd78844021e948ceb633d1dcee3f7885561b5d9/ofl/cinzel/OFL.txt). Static 400/600/700 instances were generated with FontTools; their family/style names are explicit because the variable source's STAT table lacks a named 600 entry. The source hash, instance hashes, conversion and license hash are recorded in `Fonts/FontProvenance.json`. No paid font/service was used.

Source Serif 4 static sources and OFL notice were copied into the new theme, preserving the existing originals. Font atlases, materials, weights and fallbacks are theme-local. TMP's shader and shared view/scripts remain legitimate shared dependencies and are listed in the Unity validation report; they are not legacy design-art deletion targets.

## Regeneration

Unity menu `Fishing Cards/UI/Midnight Field Journal` contains:

1. **Prepare Isolated Assets**: imports the first audited staging set, or verifies existing canonical inputs after staging is gone. Conflicting source bytes or destinations stop preparation rather than overwriting unrelated content.
2. **Build Isolated Fonts And Theme**: creates/reuses isolated font assets and visual mappings; new supported authored characters can be appended without changing font GUIDs.
3. **Build Reusable Templates**: regenerates only candidate prefabs using canonical art and theme fonts; it neither generates replacement artwork nor installs/saves a scene.
4. **Validate Isolated Resources**: verifies imports, font boundaries, template regeneration and active-scene state.
5. **Capture Resource Sheet**: renders a 3840 × 2160 resource/font sheet in a disposable Editor preview scene, then disposes it without changing the active scene.

Normal regeneration was also executed successfully with the entire ignored `Temp/MidnightFieldJournal` staging directory temporarily absent. Assets, font sources and license notices required by the checked-in templates are project-local.
