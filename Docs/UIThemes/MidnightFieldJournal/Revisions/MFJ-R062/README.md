# MFJ-R062 — Equipment Card Table

**Alternative design in Penpot. Ready for review; no Unity integration.**

Location: **01 - Current Design Library → 01 - Current Screens and Gameplay Reference → MFJ-R062 / Tackle Shop / Equipment Card Table**, at (80000, 7000). Canvas: 3840 × 2160. Selected in the Penpot viewport.

This concept uses only the existing in-game dark paper/kelp background, compact Catch Chain frames, collectible-card marine borders, Cinzel and Source Serif 4. No shop panorama, workshop scene, full-screen shop art, R061 cabinet frames or newly generated illustration is used. Source card art remains independent and is downscaled for this layout; no full-screen screenshot is sliced.

Three horizontal rig slots sit above the collection. The catalog presents large tactile equipment cards with their existing item illustrations, names, ownership states and effects. The owned Reel is raised slightly and has a direct Equip action. Rod is equipped; Reel is owned but not equipped; Hook is available to unlock for 250 Gold. Sample wallet is 650 Gold. All sample fields remain editable.

Up to one Rod, one Reel and one Hook may be equipped simultaneously. Slots may be empty. Purchase ownership and equipment are separate. No additional items, currencies or effect changes are introduced. An equipped item's selection/removal and category browsing remain future implementation requirements; this is a visual review. Only the Harbor back link is wired.

R061 and all prior screens remain unchanged. **R061 and R062 are alternatives for review, not cumulative imports.** Unity still has its current equipment behavior until a design and implementation are requested.
