The user found the current imported controls too metallic. This version uses newly generated aged ivory parchment, flat sepia ink borders, worn paper edges, subtle chart-like marks and faded navy marine fronds, matching the cards’ naturalist journal style. Cinzel70 titles and slender printed direction chevrons replace the bronze/enamel treatment. Both controls remain exactly880×350. Text and direction vectors remain editable, separate from the1988×791 blank image. Individual static face exports are retained for a potential later Unity import under the existing baked-action-label exception. No image was sliced from a mockup; generation used the built-in imagegen tool with the existing Technique frame as a style reference.

The source review board is `MFJ-R037–R038 / Parchment controls / card-style alternative`. The separate full-size **GAMEPLAY E / Parchment controls / MFJ-R037–R038** shows both buttons and the new Line Load beside the existing cards. Gameplay E is a clone of Gameplay D; only its copied controls are replaced, leaving original assemblies untouched. Existing hints, positions, cards, chain, fan and haul are preserved. A separate source board holds both independent blank images.

Readback verified four equal-sized button views (two sources, two Gameplay E instances), correct labels and vector icons, and hidden former controls in the copy.
