# MFJ-R066 — Original 4K Shop Background

**Penpot only, ready for review. Unity unchanged.**

Find **01 - Current Design Library → 01 - Current Screens and Gameplay Reference → MFJ-R066 / Tackle Shop / Original 4K Background** at (80000, 27000). Scrolled review at (84200, 27000). Both screens are 3840 × 2160. Independent background master under Source Art at (88800, 27000).

The entire old visible background, including the R057 paper ornament master and its 9-slice cells, is hidden. Its preserved draft is not used to construct the replacement. The new background combines original native-size vector parchment, ink edging, hand-drawn rigging-line curls and paper grain with a newly generated independent spool/float/coastal seed-pod engraving. The 1536 × 1024 engraving displays at 210 × 140 or smaller. Two mirrored page-corner instances and one navy-margin instance use the same new asset. No source artwork is enlarged.

The complete background is exported directly from the new Penpot master at **3840 × 2160**, with no cards, labels or controls baked in. The initial whole-background image-generation concept was only 1672 × 941, so it is reference-only and never displayed or enlarged. The final SVG is the vector base; the separate raster ornament placements are recorded in BackgroundManifest.json. The complete PNG is a native 4K export of both.

Equipment cards, names, effects, fields, proportions, empty slots, nine placeholders, viewport, fixed right card and discrete scroll-state links retain the R065 geometry and behavior. Only the background changes. The new edge rules clear navigation and catalog hint. Old versions remain preserved, with R065 marked superseded in the change log. No Unity code, image, prefab, scene, gameplay or save was modified.
