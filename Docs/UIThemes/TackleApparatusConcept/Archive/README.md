# Resolution experiment archive

The current working UI is 1920 × 1080 with the initial sprite dimensions. The user deferred higher-resolution work and explicitly ruled out the separate image API workflow.

`4KPreviews/` and the sibling `../Deepwater-UI-Kit-4K.zip` preserve the earlier enlarged exports for reference. They contain enlarged raster artwork, not newly painted native 4K detail. Their Penpot IDs identify mutable components that have since returned to the original working size.

The current handoff is `../Deepwater-UI-Kit.zip`; the editable library remains on Penpot pages 05–09. Original sources and prompts are preserved under `../AssetLibrary/Sources/`.
