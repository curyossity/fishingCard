# Creature sprite integration — 14 November 2026

All 22 selected sprites from Penpot's **10 - Creature Sprites** page replace creature illustrations in the game: 20 standard species and two existing Apex creatures. The eight-arm selected Small Octopus is used; its discarded variant is excluded.

`CreatureSpriteSetup.Install()` is available as **Fishing Cards > Artwork > Integrate Creature Sprites**. It verifies complete roster identity and original hashes, crops only transparent margins, adds four pixels of transparent padding and imports without resampling. Point filtering, uncompressed color, Full Rect sprite meshes, 100 pixels per unit, no mipmaps and disabled Read/Write preserve the supplied art. Original images and generated-media provenance remain under `Docs/UIThemes/TackleApparatusConcept/CreatureSprites/`. `Assets/UIThemes/TackleApparatus/CreatureSpriteImports.json` records derived hashes and crop bounds.

Creature definitions now supply the authoritative species artwork. Old four-creature Tackle lookup arrays are removed; rig and Landing views no longer fall back to those images. Journal central/compact views also use the current creature definitions. Existing card frames, native text, role-aware value, non-creature imagery and gameplay rules retain their responsibilities. Standalone illustrations use masked regions with neutral transforms; the old Squid face no longer supplies baked-in creature art. Tackle portraits preserve aspect ratio and center silhouettes inside their existing rectangles, including narrow/tall creatures. Long rig names fit within the dark nameplate. Discover/Landing regeneration calls the same import path.

`CreatureSpriteChecks.Validate()` checks all 22 species through actual Tackle rig, Landing portrait, Journal central and Journal compact prefabs. It verifies exact definition references, source hashes, crop dimensions, import settings, name fitting and preservation of the generic moving Landing indicator. See `Verification.json` for the assertion count and [all-species native-size rig review](RigRoster.png).

Final results: 222 creature-view assertions, 155 Discover asset assertions, 96 Landing asset assertions, 64 Landing rule assertions, 16 live Discover assertions and 46 live Landing assertions passed. The Unity metadata checker reported zero errors and zero warnings across 1,638 files; compilation and live checks produced no errors. Existing Unity 6.5 deprecation warnings in unrelated editor utilities remain. `ImportedPixelValidation.json` confirms every RGBA sample in all 22 derived sprites matches its source crop and each four-pixel border is transparent. `GameplayDataAudit.json` confirms existing gameplay values are unchanged; Unity additionally serialized previously omitted default-valued fields.

The real Landing scene was also exercised with persistence disabled: separate Discover/Landing visibility, eight ordered rig cards, scrolling, native strike hit targets, scoring geometry and button feedback. Captures at 1920 × 1080, 1280 × 800 and 2560 × 1080 are in `Landing/`. Creature art validation does not change creature unlocks or manufacture a run reward. The generic moving fish icon and its two-thirds-Perfect-zone width remain independent of encountered-species portraits.
