# Deepwater water impact authoring

`card-impact.mjs` is an original effect authored for the narrow vertical seam between the Landing creature and score cards. It uses the installed PixelFX painter, palette fitting and seeded RNG; no premade effect is shipped. Technical references inspected: PixelFX water splash, bubbles, shield-block, sword-slash, frost-nova and small-explosion recipes. The actual sheet has no actor, floor, scenery, text or gallery font.

Run from the project root:

```powershell
node Tools/PixelFX/render-impact.mjs
node .local-tools/pixelfx/tools/check.mjs 'deepwater/card-impact*'
```

The renderer imports the existing ignored `.local-tools/pixelfx` installation. It writes the three runtime PNG sheets into `Assets/FishingUIAssets/Effects/WaterImpact`, stable metadata beside this recipe, and contact sheets under `Docs/Validation/WaterImpact/Art`. An optional first argument selects a different preview folder. Tiny wrappers expose the maintained source to the local PixelFX checker; the ignored wrappers are regenerated by this command.

The Unity `LandingWaterImpactSetup` reads the frame, grid and pivot metadata, imports point-filtered uncompressed alpha textures without mipmaps, and binds the saved Landing prefab. Run `LandingScoreRushSetup.Install()` in Edit mode after reauthoring to rebind changed metadata. The three authored tiers and gain thresholds are presentation tuning: Small uses power .2, Medium .58, Large 1; runtime selection follows `LandingScoreSequence.Step.Strength` at thresholds .28 and .7. Base accuracy uses strength .24.

Each atlas has 25 frames at 60 fps (400 ms including the empty endpoint), frame size 96x144, origin 48x72, seven columns and four rows. Native display uses two reference pixels per authored pixel. Six palette colors supply dark contours, blue-green water, pale foam and warm white highlights. The contact is immediate; jets thin away by 100 ms, droplets arc with drag, then small hollow bubbles rise. The score punch peaks immediately at contact, scales only the number by roughly 5-14%, and settles in 160 ms.

Four visual drafts were rendered. The first was too much like a thin electrical spark; the second widened the liquid sheets; the third removed a collapsing horizontal line artifact; the fourth rounded the tips, bent the jets asymmetrically and added foam highlights after inspecting the effect in the real cabinet. Native consecutive frames confirm that the collision, identity and score remain legible. Larger ripples and a dash wake remain separate optional additions.

PixelFX upstream: https://github.com/patch-gg/pixelfx (MIT). Its license and notices are retained here and alongside the runtime exports. The reserved gallery font is not included. All authoring and export run locally with no credentials or hosted services.
